VOLOX MAX INDIA 3.0 — RED & YELLOW EDITION

CONTENTS
- index.html: complete app structure
- style.css: responsive red/yellow game UI
- script.js: character roster, local profile, activities, missions, XP, credits and local save data

RUN
1. Keep all three files in the same folder.
2. Open index.html in a modern browser, or upload the folder contents to your static hosting provider.
3. On mobile, open the hosted page in Chrome. The interface adapts to phone screens.

INCLUDED PLAYABLE OFFLINE ACTIVITIES
- Skyline Sprint: checkpoint time trial
- Frontier Expedition: landmark discovery
- Neon Puzzle: sequence memory puzzle

CHARACTERS
Includes all 66 character names supplied for this project. Character cards use original abstract letter-mark placeholders; no official character artwork or copied game assets are included. Thala is labelled as a VoloX India exclusive concept.

IMPORTANT SCOPE
This is a complete offline browser game hub with three playable activities and local progress storage. It is not an online multiplayer/3D battle royale product. Real accounts, cloud saves, matchmaking, live leaderboards, 3D character models, official licensed art, and server-hosted multiplayer require separate backend services, game assets, licensing, and deployment. No such services are represented as implemented here.

PROGRESS DATA
Progress is saved in the browser's localStorage on the current device. Clearing browser site data removes local progress. There is no cloud backup in this build.
